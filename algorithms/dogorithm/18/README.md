# 역순 반복 구간 찾기

## 실행 계약

문제 원문을 확보하지 못해, 기존 `invert.cpp`의 탐색 조건을 아래와 같이 명시했다. 공식 문제의 정답 확인과 구분한다.

- 현재 작업 폴더의 `S.txt`에서 문자열을 읽고, 표준 입력으로 `0 <= L <= H`를 받는다.
- 길이가 같은 두 구간이 역순으로 같고, 겹치지 않으며, 구간 사이의 문자 개수가 L 이상 H 이하인 쌍을 찾는다.
- 길이가 가장 긴 쌍을 선택한다. 동점이면 왼쪽 시작점, 오른쪽 시작점이 작은 순서로 선택한다.
- 좌표는 1부터 시작하는 양 끝 포함 구간이며, 해가 없으면 `0`을 출력한다.

```sh
cd algorithms/dogorithm/18
../../../out/build/linux-debug/bin/dog_18_invert < 01.inp
```

Windows에서는 같은 폴더에서 `../../../out/build/windows-debug/bin/dog_18_invert.exe`를 실행하고 표준 입력에 `3 7`을 입력한다.

## 원본 자료와 검증 결과

`01.out`·`02.out`은 가져온 원본을 수정하지 않고 보존했다. 현재 `S.txt`에서는 그 좌표의 두 구간이 역순으로 같지 않다. 0부터 시작하는 좌표로 해석해도 일치하지 않는다. 따라서 이 파일을 현재 문자열의 정답으로 사용하지 않는다.

| 입력 | 원본 출력 | 위 계약으로 독립 검산한 출력 |
|---|---|---|
| 3 7 | 57716 57725 57732 57741 | 27043 27052 27056 27065 |
| 100 500 | 54492 54501 55002 55011 | 55818 55830 55961 55973 |

검산 결과는 원본과 구분한 `01.verified.out`·`02.verified.out`에 둔다. 기대값을 프로그램 출력에서 복사하는 대신, `tests/invert.cpp`가 모든 길이의 부분 문자열을 모아 역순과 직접 비교하는 독립 참조 구현으로 최대 길이와 동점 순서를 확인한다. 접미사 배열을 쓰는 실행 코드와 다른 방식이다.

CTest는 길이 0~8인 a/c 문자열의 모든 조합과 간격 범위, 고정 난수로 만든 a/c/g/t 문자열 300개, 원본 긴 문자열의 두 간격 범위를 비교한다. 이 검증은 위 실행 계약에 대한 검증이며, 확보하지 못한 공식 문제 정의까지 확인한 것은 아니다.
