# 관련 추천문제(삼분탐색, 이분탐색, 부동소수점 오차 문제(엡실론(Epsilon, 1e-9)문제))

### 알겠습니다! 딱 원하시는 대로 **삼분 탐색(Ternary Search), 기하학, 그리고 부동소수점 오차**를 다루는 감각을 키우기 좋은 백준과 프로그래머스 문제들을 3개씩 바로 쏴드릴게요.

---

### 🎯 백준 (BOJ) 추천 문제 3선
현재 푸시는 '우주 정거장' 문제와 가장 결이 비슷한 **기하학 + 삼분 탐색** 세트입니다.

1. **[BOJ 11664] 선분과 점** (난이도: 실버 1)
   * **특징:** 3차원 공간에서 선분 하나와 점 하나가 주어질 때 최소 거리를 구하는 문제입니다. 
   * **추천 이유:** 지금 푸시는 '선분 vs 선분' 문제의 완벽한 **하위 호환(기초) 버전**입니다. 여기서 3차원 좌표계 삼분 탐색의 감을 딱 잡고 넘어가기 좋습니다.
2. **[BOJ 11662] 민호와 강호** (난이도: 골드 5)
   * **특징:** 2차원 평면에서 각자의 선분 위를 같은 시간에 일정한 속도로 걸어가는 두 사람 사이의 최소 거리를 구합니다.
   * **추천 이유:** 선분 2개가 등장하고, 거리가 줄어들었다가 다시 늘어나는 '볼록(Convex)' 함수 형태를 띱니다. 삼분 탐색을 적용하기에 아주 교과서적인 문제입니다.
3. **[BOJ 8986] 전봇대** (난이도: 플래티넘 5)
   * **특징:** 1차원 직선 위의 전봇대들을 일정한 간격으로 배치할 때, 이동 거리의 합이 최소가 되는 간격을 찾는 문제입니다.
   * **추천 이유:** 기하학은 아니지만, **"수식이 아래로 볼록한 2차 함수 형태일 때 삼분 탐색으로 최솟값을 찾는다"**는 원리를 가장 명확하게 훈련할 수 있는 명작 문제입니다.

### 🎯 프로그래머스 추천 문제 3선
프로그래머스에는 순수 3차원 기하학+삼분 탐색 문제가 거의 없습니다. 대신 삼분 탐색의 사촌 격인 **매개변수 탐색(이분 탐색 심화)**과 **좌표/정밀도 계산**을 요구하는 문제들로 뽑았습니다.

1. **교점에 별 만들기** (Level 2)
   * **특징:** 여러 개의 직선 방정식이 주어지고, 교점들 중 '정수 좌표'인 것들만 골라 격자판에 별을 찍는 문제입니다.
   * **추천 이유:** 부동소수점 오차 없이 두 직선의 교점을 수학적으로 깔끔하게 구해내는(분수 형태 처리) 능력을 테스트하기 아주 좋습니다.
2. **입국심사** (Level 3)
   * **특징:** 심사관들의 심사 시간이 다를 때, 모든 사람이 심사를 받는데 걸리는 '최소 시간'을 이분 탐색으로 찾습니다.
   * **추천 이유:** 반복문을 통한 탐색 알고리즘의 대명사입니다. 삼분 탐색을 하려면 탐색 범위를 좁혀나가는 이분 탐색/매개변수 탐색의 뼈대가 완벽해야 하므로 무조건 풀어봐야 합니다.
3. **금과 은 운반하기** (Level 3)
   * **특징:** 주어진 시간 내에 새 도시를 건설하기 위한 금과 은을 모두 운반할 수 있는지 판별하고 최솟값을 찾습니다.
   * **추천 이유:** 탐색 범위가 $10^{14}$ 이상으로 무지막지하게 큽니다. 오차나 자료형의 한계를 생각하며 `left`, `right`, `mid` 값을 쪼개는 훈련을 하기에 최고입니다.

### 배정밀도(Double Precision) 부동소수점 오차, 일명 **엡실론(Epsilon, 1e-9)** 처리가 완벽하게 안 되면 맞왜틀(맞았는데 왜 틀리지) 지옥에 빠지는 문제들로 싹 다 뽑아드릴게요. 

이런 문제들은 앞서 배운 `1e-9`를 더하거나 빼는 스킬, 혹은 `abs(A - B) < 1e-9` 같은 오차 허용 비교법을 실전에서 연습하기 최고입니다.

### 🎯 백준(BOJ) 부동소수점 오차 극복 문제 3선

**1. [BOJ 1064] 평행사변형 (실버 1)**
* **특징:** 세 개의 점이 주어질 때, 만들 수 있는 평행사변형 둘레의 최댓값과 최솟값의 차이를 구하는 문제입니다.
* **왜 이 문제인가?** 길이를 구하려면 루트(`sqrt`)를 써야 하는데, 실수 값 두 개가 '같은지' 비교해야 하는 순간이 옵니다. 이때 `if (len1 == len2)`라고 쓰면 부동소수점 오차 때문에 100% 틀립니다. `if (abs(len1 - len2) < 1e-9)` 처럼 오차 범위를 직접 지정해서 비교하는 법을 연습하기 가장 좋은 기초 문제입니다.

**2. [BOJ 1002] 터렛 (실버 3)**
* **특징:** 두 원의 중심 좌표와 반지름이 주어졌을 때, 교점의 개수를 구하는 아주 유명한 기하학 기초 문제입니다.
* **왜 이 문제인가?** 두 원의 중심 사이의 거리 $d$와 두 반지름의 합/차를 비교해야 합니다. $d$를 구할 때 루트를 씌운 실수 값으로 비교하면 오차 때문에 틀리기 쉽습니다. 실수를 다룰 때 생기는 오차를 경험하고, 아예 루트를 벗겨서 정수(제곱 값)로만 비교하도록 코드를 고치는 '우회법'을 배우기 좋습니다.

**3. [BOJ 7869] 두 원 (골드 2)**
* **특징:** 두 원이 겹치는 부분의 넓이를 구해서 소수점 셋째 자리까지 출력하는 문제입니다.
* **왜 이 문제인가?** 실수 계산의 **끝판왕**입니다. 삼각함수(`acos`, `sin`)와 원주율(`M_PI`)이 난무합니다. 계산 과정에서 부동소수점 오차가 눈덩이처럼 불어나기 때문에, 어느 타이밍에 실수를 처리할지, 오차를 어떻게 방어할지 뼈저리게 느낄 수 있는 매운맛 문제입니다.

### 🎯 프로그래머스 부동소수점 오차 극복 문제 3선

**1. 두 원 사이의 정수 쌍 (Level 2)**
* **특징:** 두 원 사이의 도넛 모양 공간에 들어가는 '정수 좌표(x, y)'의 개수를 세는 문제입니다.
* **왜 이 문제인가?** 방금 질문하셨던 `ceil`과 `1e-9`의 완벽한 실전 적용 사례입니다. $y = \sqrt{r^2 - x^2}$ 공식을 써서 y의 최대 정수 값을 찾아야 하는데, 딱 4가 나와야 할 값이 `3.999999999`로 계산되어 버림(`floor`)했을 때 3이 되는 대참사가 벌어집니다. 여기에 `+ 1e-9` 꼼수를 쓰거나 정수 연산으로 회피해야만 통과할 수 있습니다.

**2. 점 찍기 (Level 2)**
* **특징:** 원점과의 거리가 $d$ 이하인 점들 중, 특정 배수 단위로 찍힌 점의 개수를 구합니다.
* **왜 이 문제인가?** '두 원 사이의 정수 쌍' 문제의 하위 호환 느낌입니다. 역시 피타고라스의 정리를 이용해 최대로 찍을 수 있는 점의 개수를 구해야 하는데, `sqrt` 사용 시 발생하는 소수점 버림/올림의 오차를 어떻게 깔끔하게 처리할지 묻는 문제입니다.

**3. 당구 연습 (Level 2)**
* **특징:** 당구대 위에서 공을 쳐서 쿠션(벽)을 맞추고 목표 공을 맞추는 최단 거리를 구합니다.
* **왜 이 문제인가?** 전형적인 '반사 기하학' 문제입니다. 대칭 이동시킨 좌표와 내 좌표 사이의 거리를 구해야 합니다. 최단 거리를 구하기 위해 여러 경우의 수를 비교할 때, 실수 단위의 거리 비교가 필연적으로 들어갑니다. 정밀도 관리의 중요성을 톡톡히 느낄 수 있습니다.
