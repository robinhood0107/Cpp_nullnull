Goal
This exercise aims to give students hands-on experience with defining a template class in C++17. The objective is to implement a simplified version of the STL vector container called my_vector.

Concept Explanation
In previous exercises and assignments, you frequently used the STL std::vector class. When declaring a vector, you always specified the type of data it would store, for example:

std::vector<int>
std::vector<Student>
std::vector<std::string>
This is because std::vector is a template class, meaning it can operate with any data type specified at the time of instantiation.

Conceptually, std::vector<int> could be instantiated like this:

template<>
class vector {
public:
    vector(int n);
    int& operator[](int index);
    ...
private:
    int _size;
    int* _data;
};
Similarly, std::vector<Student> would look like:

template<>
class vector {
public:
    vector(int n);
    Student& operator[](int index);
    ...
private:
    int _size;
    Student* _data;
};
Classes or Functions to Implement
You are to implement the following in my_vector.h:

Class: my_vector<T>
explicit my_vector(size_t N=0) noexcept: Constructor to allocate an array of size N.
my_vector(std::initializer_list<int> lst) noexcept: Constructor to initialize from a list.
my_vector(const my_vector<T>& other) noexcept: Copy constructor (deep copy).
T& operator[](int i): Overloaded subscript operator to access elements.
size_t size() const: Function to return the number of elements.
Member Variables:
size_t _size: The number of elements in the vector.
T* _data: Raw pointer to the dynamic array storing the elements. You must manage memory manually, including proper allocation, deallocation, and copying.
Constraints
Avoid memory leaks or shallow copying.
