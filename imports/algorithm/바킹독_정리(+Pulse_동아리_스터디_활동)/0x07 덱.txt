restricted structure = 특정한 위치에만 원소를 넣거나 뺄 수 있게 제한이 걸려있는 자료구조를 묶어서 부르는 말
큐,스택, 덱을 restricted structure라고 한다.


양쪽 끝에서 삽입과 삭제가 가능하다

덱은 deque로 double ended queue라고 한다
카드게임할때의 그 deck이다.

스택은 한쪽에서만 삽입 삭제
큐는 뒤에서 삽입 앞에서 삭제
덱은 앞, 뒤에서 삽입과 삭제가 가능하다

덱도 역시 마찬가지로
원소 추가 O(1)
원소 제거 O(1)
앞 뒤의 원소확인 O(1)
제일 앞 뒤가 아닌 경우에는 원소 확인이 불가능

STL deque의 특이한 점 = stl의 경우에는 인덱스로 원소에 접근할 수 있다.

구현
dat[2*MX+1]
head = MX, tail=MX라고 한다
head는 가장 앞에 있는 원소의 인덱스
tail은 가장 뒤에 있는 원소의 인덱스+1
head와 tail의 초깃값이 MX인 이유는 덱은 양쪽에서 삽입과 삭제가 일어나야 하기 때문에 양쪽확장을 위해서 시작지점을 중간으로 두어야 한다.


원형으로 할 수도 있지만
코딩테스트에서는 크게 잡으면 되서 선형으로 한다.

push_front(int x){
	data[--head]=x;
}
head는 기본적으로 가장 앞의 원소를 가리키기때문에
계산시에 미리 1을 빼서 인덱스를 더 앞으로 옮긴 다음에 앞에 원소를 옮겨야 한다

push_back(int x){
	data[tail++]=x;
}
tail은 기본적으로 가장 뒤에 있는 원소에서 1 더큰 인덱스를 기본적으로 지시하고 있음
그러니까 그냥 넣은 다음에 tail을 1 증가시켜 주면 된다(증가시켜주는거 잊지마)

pop_front(){
	head++;
}
head를 1증가시켜버리면 삭제가 된다

pop_back(){
	tail--;
}
tail을 1 감소시켜버리면 삭제가 된다.

front(){
	data[head];
}
head는 가장 앞부분의 원소를 가리킴

back(){
	data[tail-1];
}
tail은 가장 뒷부분의 1칸 뒤 빈 인덱스를 가리킴
