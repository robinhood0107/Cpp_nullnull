0x05 스택

한쪽 끝에서만 자료를 넣고 뺄 수 있는 구조 (FILO) (먼저 들어온 것이 제일 마지막에 나간다)

스택은 배열과 시간복잡도 비슷함
원소 추가 O(1)
원소 제거 O(1)
상단 원소 확인 O(1)
상단이 아닌 원소 확인/변경은 원칙적으로 불가능하다(pop을 통해서 꺼내든가)(STL 스택도 이 기능은 없음)


스택은 배열이나 연결리스트로 구현할 수 있는데
배열로 만드는게 쉽다

(실전에서는 배열로 만들어라, C++이면 STL 쓰던가)


STL을 쓸 수 있는 환경이면 STL을 꼭 쓰자
(내가 스택 구현하면 스택에 잘못이 있다고 의심할 수 있는 여지가 생겨서 시간이 걸리지만)
(STL쓰면 이미 만들어진거 가져다 쓰는 것이라 잘 쓰기만 하면 된다)

STL stack은 다음과 같이 있음
push, pop, top, empty, size 함수가 있음

선언은 stack<int> s;
이런 방식으로 선언함

값을 넣을때는 s.push(10); s.push(300); 이런방식으로 넣으면 됨
s.pop()의 경우 그냥 이렇게 s.pop()이라고 하면 상단값 삭제
s.top()도 마찬가지고 단순하게 상단값 출력

주의할 점!!! ) s.pop()이나 s.top()은 스택이 비어있을 경우에는 런타임 오류가 발생한다(런타임 오류 조심)
(팁) 꼭 s.empty() 함수를 통해서 스택의 길이로 비어있는지 확인하고 pop,top출력해야 한다

s.empty()는 비어있으면 1 없으면 0을 출력한다 ( stack.empty() 는 현재 스택이 비었으면 true, 아니면 false를 반환합니다.) 
s.size()는 스택의 길이  (데이터 개수)를 반환

void push(int x){
	dat[pos++] = x;
}
제일 상단에 값을 집어넣고 pos를 1 증가한다.
(스택이 n개 요소 가지고 있으면 0부터 시작하는 인덱스 가질테니까 pos(제일 상단값의 위 빈 인덱스)는 n)
참고)후항연산자는 저 식 계산(x를 dat[pos]에 대입)이 끝나고 pos가 1 증가하는 것임.

void pop(){
	pos--;
}
여기서 dat[]의 제일 상단 데이터를 없애지 않는 이유는 어쩌피 나중에 push할때 덮어 씌워지기 때문이다.

void top(){
	dat[pos-1];
}
제일 상단값 출력하려면 그냥 이렇게 출력하면 된다.
