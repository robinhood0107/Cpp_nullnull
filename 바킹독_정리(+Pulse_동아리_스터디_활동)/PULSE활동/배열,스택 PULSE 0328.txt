배열이란?

메모리 상의 원소를 연속하게 배치한 자료구조.
(선형 자료구조라고는 할 수 없음, 좌표라는걸 표시 할 수 있기 때문)

a[5][5]-> a[0][4]와a[1][0]은 메모리상으로 인접해 있음

c/c+에서 차원이 n*m이다 -> 메모리상으로 길이가 m 인 1차원 배열을 n개 늘여놓은 것.


배열의 성질

k번째 원소를 확인하는데 O(1)
k번째 원소를 변경하는데 O(1)
k번째 원소를 끼워 넣을 때 O(n) -원소를 하나하나 옮겨야 하기 때문
k번째 원소를 삭제할 때 O(n) -원소를 하나하나 옮겨야 하기 때문

연결리스트
k번째 원소 확인에 O(n), k번째 원소를 끼워 넣을 때 O(1)

a -> b -> c -> d -> e

인덱스 없이 node로만(포인터로 구현) 다음 요소를 가리킴
(인덱스가 없어서 O(n)으로 원소 확인)

캐시  = 메인메모리까지 접근하는데 시간이 걸림 
미리 가져와서 캐시 메모리에 필요한 값을 미리 저장해둠
중복되는 값은 캐시메모리에서 바로 가져올 수 있게 함

캐시메모리 단점 = 메모리 상에서 연속된 구간을 잡아야 하기 때문에 할당에 제약이 걸림
예시로 a[0] -> a[1000000]이면 꼼짝없이 1000000을 구간 잡아야 됨

python에서는 numpy에서 np.array로 배열 구현, 백준에서는 numpy를 지원하지 않기 때문에 list를 사용해야 함
list는 심지어 배열구조가 아니기 때문에 접근이 느리다.(파이썬으로 짤 경우에는 시간 고려해서 짜야 함)(시간초과 주의)


counting sort 카운팅 정렬

배열 출력하면 바로 오름차순으로 정렬됨(애초에 넣을때부터 정렬되니까)
