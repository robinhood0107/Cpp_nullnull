Goal
This lab exercise aims to provide practice in defining constructors for a user-defined class in C++. Specifically, students will implement a complex number class by providing appropriate constructors to support object creation with various input patterns. This assignment also provides practical exposure to how implicit and explicit type conversions work in C++.

Concept Explanation
A complex number is a number that comprises a real part and an imaginary part. It is typically expressed in the form a + bi, where a is the real part and b is the imaginary part.

In C++, we can represent a complex number using a class with two member variables: one for the real part and one for the imaginary part. To instantiate such a class with various initial values, we need to define multiple constructors.

The default constructor allows you to create an object with default values (e.g., 0 for both parts), while overloaded constructors allow initialization with one or two user-supplied values. Understanding when to use explicit for constructors is crucial to control implicit conversions.

You will also be introduced to how constructors interact with list initialization (using {}), copy initialization (using =), and direct initialization (using ()).

Classes or Functions to Implement
You need to complete the definition of the complex class by adding appropriate constructors to support the usages in main.cpp. Follow these requirements:

Class: complex
Member Variables:

double i{0}; — imaginary part of the complex number (initialized to 0).
Member Functions:

complex() — Default constructor. Initializes r and i to 0. Already handled by in-class initializers.
complex(double real) — Single-parameter constructor. Initializes r to real and i to 0. Hint: Allow implicit conversion to support calls like complex c = 1;.
complex(double real, double imag) — Two-parameter constructor. Initializes r to real and i to imag.
complex add(const complex& c) — Returns the sum of two complex numbers. Hint: You may use STL algorithms such as std::transform with arrays if you convert real and imaginary parts into containers.
Friend Functions:

friend std::ostream& operator<<(std::ostream& os, const complex& c) — For formatted output of complex numbers.
