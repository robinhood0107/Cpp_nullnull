0x0B강 - 재귀


재귀 : 하나의 함수에서 자기 자신을 다시 호출해 작업을 수행하는 알고리즘 

재귀로 n부터 1까지 출력하는 함수
void func1(int n){
	if(n==0) return;
	cout << n << ' ';
	func1(n-1);
}

재귀로 1부터 n까지의 합을 구하는 함수
void func2(int n){
	if(n==0) return 0 ;
	return n+func2(n-1); // n에 n-1더하고 n-2더하고 ... 계속 이렇게 내려간다
}




도미노가 쓰러지는 것에 대해 설명하는 방식 

1. 순차적 설명
1 -> 2 -> 3 -> 4 ... 이렇게 1이 쓰러지면 2가 쓰러지고 ... 이렇게 설명하는 방식

2. 수학적 귀납법
1번 도미노가 쓰러짐.
k번 도미노가 쓰러지면 k+1번 도미노가 쓰러진다


즉 재귀를 하려면 1번과 같은 절차지향적인 사고를 탈피해야 한다.

func1을 절차지향적으로 따라가게 되면 
3 -> func1(2) 호출 -> 2 -> func1(1) 호출 -> 1 ... 이런방식으로 설명하게 될 것임.

귀납적인 사고로 생각을 해보자
func1(k)가 k k-1 k-2 ... 1을 출력하면
func1(k+1)은 k+1 k k-1 k-2 ... 1를 출력한다.

즉, k+1 출력 -> func1(k) 호출 (= k k-1 k-2 ... 1) 출력



재귀함수의 조건
base condition, base case = 특정 입력에 대해서는 자기 자신을 호출하지 않고 종료되어야만 한다!(자기 자신을 호출하면 안됨)
즉, 어떤 입력에 대해서는 반드시 자기 자신을 호출하지 않도록 해야 하는데 (재귀종료조건 정도로 생각) 이걸 base condition이라고 한다.

그리고 모든 입력은 base condition에 수렴해야 한다.
void func1(int n){
	if(n==0) return;
	cout << n << ' ';
	func1(n-1);
}
여기서 base condition은 if(n==0) return; 이 된다
n = 0 일때 자기 자신을 호출하지 않고 종료가 되서 이걸 base condition라고 한다
